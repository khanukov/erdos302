Run the finite exact verification paths from this directory:

```bash
python3 -I -S -O exact_certificate.py
python3 -I -S -O verify_certificate.py
python3 -I -S -O hierarchical_certificate.py verify \
  certificate.json --base-verifier exact_certificate.py
python3 -I -S -O crosscheck_reciprocal_edges.py
python3 -I -S -O verify_wang_two_tail_baseline.py
python3 -I -S -O test_upper_mutations.py
```

`exact_certificate.py` and `verify_certificate.py` are algorithmically
separate exhaustive checks of the \(Q=3360\) base demands. The hierarchical
checker validates the \(Q=139708800\) certificate, while the factorisation
script reconstructs its complete edge set independently. The Wang script
exactly checks the finite tile edges, prefix covers, and rational-density
arithmetic used in this repository's \(2125/2418\) comparison; multiplier-block
disjointness and asymptotic transfer remain human arguments. It does not verify
Wang's Problem 301 theorem. `VERIFICATION.txt` records the accepted outputs and
mutation-test results generated at packaging time.
