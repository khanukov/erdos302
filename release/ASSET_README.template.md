Run the finite exact verification paths from this directory:

```bash
python3 -I -S -O exact_certificate.py
python3 -I -S -O verify_certificate.py
python3 -I -S -O hierarchical_certificate.py verify \
  certificate.json --base-verifier exact_certificate.py
```

`exact_certificate.py` and `verify_certificate.py` are algorithmically
separate exhaustive checks of the \(Q=3360\) base demands. The hierarchical
checker validates the \(Q=139708800\) certificate. `VERIFICATION.txt` records
the accepted outputs and mutation-test results generated at packaging time.

full source archive for tag `@TAG@`; follow `REPRODUCIBILITY.md` there.
