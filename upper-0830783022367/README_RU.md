# Задача Эрдёша № 302 и верхняя граница 0,830783022367

Пусть \(f(N)\) — наибольшая мощность множества \(A\subseteq\{1,\ldots,N\}\), в котором нет различных \(a,b,c\) с \(1/a=1/b+1/c\). Компьютерное доказательство даёт

\[
\limsup_{N\to\infty}\frac{f(N)}{N}\le C
=0{,}83078302236617795246122302935832897569\ldots
<0{,}830783022367.
\]

В `paper/` находятся рукопись на английском и её исходник LaTeX. В `certificate/` находится исходный C++17/Python-сертификат. `lean/` содержит проект Lean, `checks/` — протоколы новой проверки и точные внутренние поправки в сжатом виде. Русское описание оригинальных вычислительных свидетелей находится в `certificate/README_RU.md`.

## Как получается коэффициент

| Часть | Вклад в нижнюю оценку доли пропусков |
| --- | --- |
| Внутренние блоки, гладкие относительно простых до 5003 | 0,1690356709665729567692182714946712… |
| Внешние тройки с единичным масштабом и дополнительные масштабы без внутренних простых | 0,0001743788090915927106086879036720… |
| Дополнительные масштабы при ровно одном внутреннем простом | 0,0000069278581574980589500112433278… |

Внутренний расчёт оплачивается пропусками только на вершинах, входящих во внутренние тройки. Внешние тройки используют изолированные внутри этих блоков вершины. Поэтому их вклады складываются. Для каждого конечного интервала множителей подсчёт точен на кратных общего периода. Монотонность \(f(N)\) затем даёт утверждение для \(\limsup\). Направление всех округлений сохраняет нижнюю оценку числа пропусков. Запас между точным \(C\) и напечатанным десятичным пределом составляет около \(8{,}22\cdot10^{-13}\).

Итоговая декларация `Formal302.upper_0830783022367_of_certificate` доказывает строгую оценку для экстремальной функции из Formal Conjectures. Она принимает явные конечные гипотезы `InputSpec`, `RanksThrough`, условия на внешние строки и совпадение сумм по исходным свидетелям с тремя проверенными числителями. **Сквозная теорема для конкретного файла свидетелей в Lean остаётся открытой.** Внутренние локальные ранги и поток всех внешних троек проверяют программы на C++17 и Python. В проекте Lean эти результаты остаются гипотезами итоговой декларации. Ядро проверяет общие шаги и сохранённые таблицы с помощью обычных тактик Lean и `decide +kernel`.

Отдельно программа `Replay302Cells.lean` выполняет проверенный шаг над каждой исходной записью и подсчитывает её целочисленный вклад. Она обработала 3 094 631 интервал положительных поправок и воспроизвела таблицу масс для 249 непустых уровней. Проверка всего файла выполняется при запуске программы Lean. Доказательство ядром относится к правилу проверки и его применению к спискам записей.

## Воспроизведение

В репозитории список троек хранится в сжатом виде. В корне проекта
восстановите исходный файл перед проверкой.

```sh
xz -dc certificate/shortlist.bin.xz > certificate/shortlist.bin
```

Из корня проекта выполните команды ниже.

```sh
sha256sum -c SHA256SUMS
python3 certificate/verify.py
python3 certificate/verify.py --exterior
python3 certificate/verify.py --full work
```

Первая команда проверяет целостность пакета. В режиме по умолчанию Python пересчитывает дроби по сохранённым таблицам. Режим `--exterior` заново генерирует и проверяет внешние тройки. Режим `--full` дополнительно восстанавливает внутренние свидетели и ранги. Полный прогон требует 64-битной системы, Python 3.10 или новее, C++17 с `__int128` и несколько гигабайт свободного дискового пространства.

Версии Lean и mathlib закреплены в `lean/lean-toolchain` и `lean/lake-manifest.json`. Проверьте проект командой `lake build` из `lean/`. При первом запуске можно загрузить кэш нужных зависимостей:

```sh
cd lean
lake exe cache get Mathlib.Data.Nat.Totient Mathlib.Algebra.Order.BigOperators.Group.Finset Mathlib.Order.Interval.Finset.Nat Mathlib.Order.LiminfLimsup Mathlib.Algebra.Order.Archimedean.Real.Basic Mathlib.Tactic.Ring Mathlib.Tactic.FieldSimp Mathlib.Tactic.Linarith Mathlib.Tactic.NormNum Mathlib.Tactic.Positivity
LEAN_NUM_THREADS=2 lake build
xz -dc ../checks/mass.cells.xz > ../checks/mass.cells
lake env lean --run Replay302Cells.lean ../checks/mass.cells ../certificate/mass.tsv
```

`Formal302.lean` и `Formal302/FrozenArithmetic.lean` выводят зависимости основных теорем через `#print axioms`. Генераторы сохранённых таблиц в `checks/gen_scales_lean.py` и `checks/gen_arithmetic_lean.py` воспроизводят их из `certificate/`. В `checks/VERIFICATION.md` указаны точные числители и описаны выполненные прогоны.
