# Задача Эрдёша № 302. Верхние оценки плотности

Через \(f(N)\) обозначим наибольшее число элементов множества \(A\subseteq\{1,\ldots,N\}\), в котором нет попарно различных \(a,b,c\) с \(bc=a(b+c)\). Для каждой строки таблицы доказано \(\limsup_{N\to\infty} f(N)/N\le C\). Числа в правом столбце округлены вверх.

| Свидетельства | Верхняя оценка |
| --- | ---: |
| Гладкие блоки, упрощённый профиль | **0,831020053520** |
| Гладкие блоки, полный профиль | **0,830964329034** |
| Полный профиль и 1 400 000 явно сохранённых троек | **0,830892297401** |
| Упрощённый профиль и по одной копии каждой внешней тройки на каждый допустимый множитель \(k\) | **0,830884075797** |
| Полный профиль и конечная упаковка с дополнительными множителями \(t\) | **0,830783022367** |

Ранее полученное значение равно 0,83095462851946405869… . Новая нижняя оценка для числа вынужденно пропущенных знаменателей усиливает верхнюю оценку для плотности. Самое сильное неравенство выигрывает 0,0001716061532861… в этой нормировке. Точные дроби всех расчётов приведены в `result.json`. Проверка включает программу на C++17 и целочисленную арифметику Python. Полная сертификация в Lean остаётся отдельной работой.

## Внутренняя оценка

В гиперграфе на натуральных числах ребро — три различных знаменателя, удовлетворяющих уравнению. Обозначим через \(\tau(T)\) минимум числа вершин, пересекающих каждое ребро в конечном \(T\). Дополнение допустимого множества — одно из таких покрытий.

Пусть \(B_i\subseteq T\) — семейство конечных носителей с целыми весами \(w_i\ge0\), а сумма весов носителей, содержащих любую одну вершину, не превосходит \(D\). Пусть \(T'\subseteq T\). Тогда

\[
\tau(T')\ \ge\ \left\lceil\frac1D\sum_i w_i\tau(B_i\cap T')\right\rceil.
\]

Действительно, для любого покрытия \(H\) множества \(T'\) каждое пересечение \(H\cap B_i\) покрывает все рёбра в \(B_i\cap T'\). Сумма \(\sum_i w_i|H\cap B_i|\) не превосходит \(D|H|\). Этим доказана и допустимость повторной проверки одних и тех же весов при разных порогах.

Берём простые числа до 5003 в порядке \(3,2,5,7,\ldots\). Через \(S_j(x)\) обозначим целые числа до \(x\), имеющие простые делители только среди первых \(j\) простых этого списка. Для одного и того же набора весов проверяются 225 уровней гладкости. Высоты порогов заданы целочисленной сеткой с шагом \(\max(1,\lfloor x/5200\rfloor)\), а также точными концами взвешенных наборов. Каждый используемый ранг относится к конкретному конечному множеству. Шаг сетки не создаёт интерполяционных предположений.

В упрощённом профиле используются взвешенные носители и прежний банк обычных ветвлений. В полный профиль входят также 888 исходных конечных порогов и 23 конечные таблицы исключения переменных прежней версии. В оба профиля добавлено одно взвешенное семейство с простыми до 5003 и максимальным знаменателем 46 000 000, содержащее 10 801 723 строки. Ранее максимальный знаменатель при этом же наборе простых равнялся 20 500 000. Поиск весов может использовать прореживание. Проверяющая программа непосредственно пересчитывает все заявленные нагрузки, ранги и равенства.

Файлы `prior.zip` и `schedule.json` задают исходные свидетели и проверяемый перечень. Для каждой строки проверяются арифметическое равенство или точный ранг конечного шаблона, гладкость, веса и нагрузка на каждую вершину. Исходный профиль родительского банка заново строится в полном режиме. Изолированные вершины можно удалить, сохранив число покрытия. Поэтому оценка для каждого блока обеспечена пропусками на его вершинах, входящих хотя бы в одно ребро.

Разбиение \(S_j(n)\) на числа, свободные от \(p_j\), и числа, кратные \(p_j\), даёт сумму двух нижних оценок для \(\tau(S_j(n))\). Проверенный профиль \(U_j(n)\) до \(63\,000\,000\) берёт максимум суммы
\(U_{j-1}(n)+U_j(\lfloor n/p_j\rfloor)\), предыдущего значения \(U_j(n-1)\), родительского профиля и конечных оценок в этой точке. Индукция по \((j,n)\) доказывает допустимость. Дальше используется само разбиение.

Положим \(d_j(n)=U_j(n)-U_{j-1}(n)-U_j(\lfloor n/p_j\rfloor)\). Если \(d_j(n)=h>0\) на \([a,b)\), вклад этого интервала в плотность пропусков равен

\[
\prod_{i<j}(1-1/p_i)\,h\,(1/a-1/b).
\]

В самом деле, в сумме по гладким блокам разложение целого на степень \(p_j\) и свободный от \(p_j\) множитель сокращает все остальные члены при переходе от \(j-1\) к \(j\). Остаётся подсчитать \(m\in(N/b,N/a]\), взаимно простые со всеми \(p_i\) при \(i<j\). Их доля равна указанному конечному произведению по периодичности. Ячеек конечное число. Суммарная ошибка после деления на \(N\) стремится к нулю.

Для каждого интервала программа берёт \(\lfloor10^{22}h(b-a)/(ab)\rfloor\). Плотности также округляются вниз после каждого умножения. Все слагаемые неотрицательны, поэтому вычитание итоговой суммы из единицы даёт строгую по направлению верхнюю оценку. В отдельной проверке исходная программа выводит интервалы без округлений, а `audit_cells.py` восстанавливает таблицу по каждому простому с целыми числами произвольной длины.

## Короткая внешняя упаковка

У каждой строки три различных простых \(p,q,r\) из \((257,100000]\), три метки \(s_i\le64\) с простыми делителями до 31 и попарные произведения \(d_i=pq,qr,pr\). Программа проверяет уравнение задачи для \(s_i d_i\) и однократное использование каждой пары \((d_i,s_i)\) во всей таблице.

Определим \(I(s)\) как наименьшую высоту, то есть максимальный знаменатель, тройки, в которую входит \(s\). Берём \(I(1)=+\infty\). Значения для меток от 2 до 64 проверяются прямым перебором до \(64\cdot65\). Достаточность предела следует из тройки \(s,s+1,s(s+1)\). Для нечётного простого \(\ell\)
\[
I(\ell s)\ge \ell\min\{I(s),(\ell+1)/2\}.
\]
Если тройка целиком кратна \(\ell\), делим её на \(\ell\). Иначе она имеет вид \(m(uv,u(u+v),v(u+v))\), где \(u<v\) взаимно просты и \(\ell\) делит один из \(u,v,u+v\). Её высота не меньше \(\ell(\ell+1)/2\). Эта формула следует из сокращённого отношения двух правых знаменателей.

Выбирается масштаб \(k\), свободный от всех простых до верхней границы группы, содержащей \(\max(5003,p,q,r)\). Для каждой строки \(\lambda=\max_i s_i d_i\). Верхний порог \(H\) равен минимуму \(d_i I(s_i)\) и дополнительных порогов для простых делителей \(d_i\), входящих в гладкий блок. Точно, пусть \(\ell_1<\dots<\ell_m\le5003\) — такие делители \(d_i\). Для каждого из них добавляется порог
\[
d_i(\ell_j+1)/(2\ell_1\cdots\ell_{j-1}).
\]
При \(\lambda\le N/k<H\) все три вершины лежат в \([1,N]\) и изолированы внутри своих гладких блоков. Последнее следует из оценки для \(I\), применённой последовательно, и из единственного разложения каждой вершины на гладкую и свободную от малых простых части.

По вершине \(ks_id_i\) восстанавливаются два наименьших простых делителя выше 257 с учётом кратности. Это множители \(d_i\). Её часть с простыми до 31 равна \(s_i\). Следовательно, внешние тройки попарно не пересекаются и каждая вынуждает ещё один пропуск. Доля подходящих \(k\) равна \((1/\lambda-1/H)\prod_{p\le b}(1-1/p)\), где \(b\) — верхняя граница группы. Проверено 54 661 612 строк. Гарантированный вычет равен 0,00013597772287737294… . В этой версии \(t=1\). Тот же довод при верхнем конце 160000 даёт вычет 0,0001500733671346795… по 124 652 035 строкам. Для него тоже достаточно прямого перебора для меток до 64.

## Внешняя проверка по короткому явному списку

В файле `shortlist.bin` сохранены 1 400 000 строк из упаковки с простыми до 60000. Наибольшее использованное простое равно 47317. Запись занимает девять байт и содержит три беззнаковых 16-битных простых в порядке little-endian, затем три однобайтовые метки. Поиск отдавал предпочтение строкам с широкими интервалами. Для доказательства достаточно самого списка.

`shortlist.py` проверяет простоту, уравнение с различными знаменателями, уникальность каждой пары «произведение простых, метка» и обе границы интервала. Для прямой проверки высоты метки достаточно перебора левого знаменателя меньше метки или меньшего правого знаменателя между меткой и её удвоенным значением. При общих множителях \(k\) используются все простые до точного \(\max(5003,p,q,r)\) каждой строки. Направленное округление даёт вычет 0,0000720316328698923… по всему списку. Полный внутренний профиль даёт верхнюю оценку **0,830892297401**, упрощённый — **0,830948021887**. Уже первые 1 001 000 строк с полным внутренним профилем дают **0,830899987499**, что меньше 0,8309. Эти утверждения используют только масштаб \(t=1\).

## Усиленная внешняя упаковка

Верхний конец интервала простых переносится до 160000. Приняты 124 652 035 различных строк. Для \(t>1\) допускаются числа до 3 000 000 со всеми простыми делителями в \((31,257]\). Теперь вершина равна \(kts_i d_i\). Её часть с простыми в \((31,257]\) однозначно восстанавливает \(t\), так что нагрузки по-прежнему не пересекаются.

Для каждой метки проверяется \(I(s_i t)\ge t\min\{I(s_i),b\}\), где выбирается один из конечного списка порогов \(b\). Когда в строке нет простого до 5003, применим интервал
\[
\lambda\le N/(kt)<\min\{H,b\min_i d_i\}.
\]
Если в строке ровно одно простое \(\ell\le5003\), дополнительно требуется \(b\le(\ell+1)/(2t)\). Это гарантирует изолированность и для метки \(\ell s_i t\). Если внутренних простых больше, учитывается только \(t=1\). Проверены 9 581 720 строк с одним внутренним простым. Вычеты от основной таблицы и дополнительных смешанных масштабов равны соответственно 0,0001743788090915927… и 0,0000069278581574980… . Внешняя упаковка целиком даёт 0,0001813066672490907… .

Для вычисления \(I(x)\) используются делители \(x^2\). Если \(x\) стоит справа в уравнении, два других знаменателя имеют вид \(x-d,x^2/d-x\), где \(d\mid x^2\), \(d<x\), \(2d\ne x\). Минимизируется \(\max(x,x^2/d-x)\). Если \(x\) стоит слева, правые знаменатели равны \(x+d,x+x^2/d\). При \(2d\ne x\) соответствующая тройка первого вида имеет не большую высоту. Особый случай \(d=x/2\) при чётном \(x\) добавляет кандидата \(3x\). Для составной взаимно простой пары \(s,t\) все делители \((st)^2\) получаются попарным перемножением делителей \(s^2\) и \(t^2\). Проверка округляет вниз каждую положительную часть плотности.

## Сколько ещё могут дать те же строки

Для усиленной упаковки можно вычислить потолок прибавки, сохранив её список строк, базовые интервалы \([\lambda,H)\) и правило выбора \(k\). Разрешим **все** множители \(t\) с простыми делителями в \((31,257]\), даже те, которые не прошли бы проверку изолированности. Тогда сумма весов множителей равна конечному произведению
\[
\sum_t 1/t=\prod_{31<p\le257}(1-1/p)^{-1}.
\]
Переход ко всем масштабам допустим и при пределе по \(N\). Для одной строки доля копий с \(t>T\) ограничена сверху величиной \(\lambda^{-1}\sum_{t>T}1/t\) равномерно по \(N\), а этот хвост стремится к нулю. Умножение этого произведения на сумму полных длин окон с соответствующими плотностями \(k\) даёт строгую верхнюю оценку **0,000229475698** для всей внешней прибавки. В таблице нижнего округления ширины одной строки теряется меньше \(2\cdot10^{-23}\), поэтому для этого вывода прибавлены две единицы сетки на каждую строку, а плотности округлены вверх. Следовательно, при тех же строках и интервалах улучшение относительно уже выбранных масштабов меньше **0,000048170**. Это ограничение относится к указанной упаковке.

Дополнительно `ceiling.cpp` полностью снимает верхнее ограничение \(H\) и суммирует \(1/\lambda\), округляя вверх. С теми же строками и разложением множителей это даёт потолок **0,000890512063**. Оба результата проверяются в `verify.py`.

## Воспроизведение

Нужен Python 3.10 или новее. Для повторного построения свидетелей также потребуется компилятор C++17 с поддержкой целых чисел длиной 128 бит, несколько гигабайт свободного места и оперативной памяти. Команды выполняются из распакованного каталога.

| Команда | Что проверяется |
| --- | --- |
| `python3 verify.py --inside-only` | Численный итог упрощённого профиля по сохранённым внутренним массам. |
| `python3 verify.py --shortlist 1001000` | Независимая проверка указанного префикса явного списка и сложение с проверенными внутренними массами. |
| `python3 verify.py --shortlist --full work` | Восстановление внутреннего банка и проверка явного списка из 1 400 000 строк. |
| `python3 verify.py --simple` | Дополнительно целочисленный итог короткой внешней упаковки. |
| `python3 verify.py` | Все дроби и округления по сохранённым таблицам. |
| `python3 verify.py --simple --exterior` | Заново проверяются обе таблицы с одним масштабом, при верхних концах 100000 и 160000. |
| `python3 verify.py --exterior` | Заново генерируются и проверяются обе внешние упаковки, включая потолки. |
| `python3 verify.py --inside-only --full work` | Независимое построение упрощённого внутреннего профиля и повторная проверка его масс по исходным ячейкам. |
| `python3 verify.py --full work` | Сквозная проверка всех приведённых неравенств. |

Вывод `ACCEPTED` в режиме сохранённых таблиц подтверждает их контрольные суммы и итоговую арифметику. При полном прогоне конечные веса воспроизводятся и проверяются построчно.
