# Протокол проверки

Дата проверки — 20 ноября 2026 года.

## Точное значение

Итоговый коэффициент равен
$C = 1 - A/10^{44} - (B + D)/10^{73}$, где

| Числитель | Значение |
| --- | --- |
| $A$, внутренний вклад | `16903567096657295676921827149467122486521892` |
| $B$, единичные масштабы и дополнительные масштабы без внутренних простых | `1743788090915927106086879036719849167769158218772927899831427626995476` |
| $D$, дополнительные масштабы при ровно одном внутреннем простом | `69278581574980589500112433278145273232282595510455405483026004478582` |

Декларация `Formal302.full_exact_value` доказывает равенство точной
дроби из рукописи. `Formal302.full_target_arithmetic` доказывает
$C < 830783022367/10^{12}$.
