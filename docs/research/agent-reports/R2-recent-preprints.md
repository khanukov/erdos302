## 0. Executive summary

* There is **no publication or preprint (2024–2026) that improves the linear lower bound 5/8 for Problem 302 by an explicit constant.** The only new 302-specific lower-bound item anywhere is a forum comment (SamKorsky, 5 Jul 2026) giving a *sub-linear* gain  f(N) ≥ 5N/8 + N/(log N)^{β+o(1)}, β = 1 − (1+log log 3)/log 3 ≈ 0.00415, via "half-isolated" odd heads and Stef's theorem on consecutive divisors (§2.2). The only new 302-specific upper-bound item is Robert Schuh's pastebin claim f(N) ≤ (373/420+o(1))N ≈ 0.888 (§2.3), weaker than the repository's 0.8609.
* All recent *linear* lower-bound progress on the sibling problems (Sawin's positive-density set for a+b ∤ 2ab, arXiv 2607.15419; Della Pietra's 1/2+ε for 327 and for 301) uses one and the same analytic engine: **restrict to L-rough integers with a "centered" prime-factor budget (Ω_L(n,x) ≤ A log(log x/log L)+K), parametrise the conflicts by three linear forms, bound the conflict count with Tenenbaum III.3.5 + de la Bretèche–Tenenbaum's three-form mean-value theorem, and show conflicts = o_L(source).** The output is always a qualitative, non-explicit ε ≍ ρ_L/const with L astronomically large; nobody has extracted a numerical ε. This is exactly the engine already imported by `/home/user/erdos302` (5/8+δ). No source contains a route to an *explicit* constant.
* All recent upper-bound progress (Wang 667/806, rickyc 319/390, Della Pietra 15437/19344 ≈ 0.7980 for 301; Liu's smooth–rough decomposition 0.7769/0.7630 for 327; Schuh 373/420 and the repository's 0.8609 for 302) is the same "disjoint scaled smooth-tile / fiber" finite optimisation. Della Pietra's README explicitly says "no known method closes the gap" and that his lower-bound construction is capped at 7/12 because it lives in (N/3, N].
* Korsky's arXiv 2607.05823 (harmonic triples 2/a = 1/b+1/c) contains a genuinely different lower-bound *technique* — filter the odd numbers by a random affine image of a 3AP-free set in F_q, q ≍ log N, then delete "collapsed" triples — but it only yields N·exp(−c√(log log N)), i.e. it is a density-zero construction; for 302 the odd numbers are already free, so the technique does not transfer directly (see §5, idea 6).
* My own quick numerics (§6) on the ideas suggested by these sources: (a) allowing the deletion of *tails* (a greedy hitting set of the conflict hypergraph) instead of only heads gains ≈ +0.003 at N ≤ 3·10^6 (0.7285 vs 0.7257 at N = 3·10^6) and does not change the slow logarithmic decline; (b) the "half-isolated head" criterion of the SamKorsky comment already covers 69–72 % of the odd heads in (N/4,N/2) at N ≤ 4·10^5 (density 0.711–0.715), so it is a good *provable proxy* but by itself is sub-linear; (c) at N = 1000 the exact optimum keeps 112 of 249 even numbers below N/2, mostly *not* divisible by 3 and mostly in (N/4, N/2) (65 of 124), and deletes 21 highly composite numbers from the top half — a structure (rough-ish even numbers in (N/4,N/2)) that none of the published constructions exploits.

### 1.1 Problem 302 — https://www.erdosproblems.com/302  (file `r2/ep302.html`)
Status OPEN; "cannot be resolved with a finite computation". Text (verbatim, modulo TeX):
> Let f(N) be the size of the largest A ⊆ {1,…,N} such that there are no solutions to 1/a = 1/b + 1/c with distinct a,b,c ∈ A. Estimate f(N). In particular, is f(N) = (1/2+o(1))N?
> One can take either A to be all odd integers in [1,N] or all integers in [N/2,N] to show f(N) ≥ (1/2+o(1))N. Wouter van Doorn has proved (see this note) that f(N) ≤ (9/10+o(1))N. Stijn Cambie has observed that f(N) ≥ (5/8+o(1))N, taking A to be all odd integers ≤ N/4 and all integers in [N/2,N]. Stijn Cambie has also observed that, if we allow b=c, then there is a solution to this equation when |A| ≥ (2/3+o(1))N, since then there must exist some n,2n ∈ A.

Links: van Doorn's note (GitHub Woett/Mathematical-shorts), formal statement in google-deepmind/formal-conjectures `ErdosProblems/302.lean`, OEIS A390395. Comments (1) = SamKorsky (§2.2). ### 2.1 W. van Doorn, "Two-colouring and density lead to many solutions of 1/x+1/y=1/z" (note, ≤ 4 pp.) — FORUM/GitHub note, unrefereed
URL: https://github.com/Woett/Mathematical-shorts/blob/main/Two-colouring%20and%20density%20lead%20to%20solutions%20to%20an%20equation%20in%20unit%20fractions.pdf (local: `r2/vandoorn.pdf`, `r2/vandoorn.txt`).
* **Theorem 1.** c = 1/390: every 2-colouring of {1..n} has ≥ cn − log(n)^3 − 1 monochromatic distinct triples 1/x+1/y = 1/z. Tile S_1 = {6,8,9,10,12,15,18,20,24,30,36,40,60,72,90,120}; S_a pairwise disjoint for a = 16^b 27^c 25^d e, (e,30)=1.
* **Theorem 2.** |S| ≥ 9n/10 + log(n)^3 + 1 ⇒ S contains a solution. Tiles S_a = {2a,3a,6a}, a = 4^b 9^c d, (d,6)=1, and T_e = {4e,5e,20e}, e = 16^f 9^g 25^h i, (i,30)=1; disjointness by parity of 2- and 3-adic valuations; counts n/12 and n/60 → n/10 disjoint triples.
* Lower-bound content: none. (Method is the ancestor of every later upper bound.)

### 2.2 SamKorsky forum comment, 05 Jul 2026 — FORUM (unverified)
URL: https://www.erdosproblems.com/forum/discuss/302 (local `r2/forum_discuss_302.html`). Verbatim mathematical content:
> f(N) ≥ 5N/8 + N/(log N)^{β+o(1)}, β = 1 − (1+log log 3)/log 3 = 0.004154751497404….
> Let A_0 = {n ≤ N/4 odd} ∪ [N/2,N]. Call an odd integer a **half-isolated** if no divisor d | a² lies in [a/2, a). If E ⊂ (N/4,N/2) consists of half-isolated odd integers then A_0 ∪ E is solution-free: any new solution has a ∈ E, so b,c are even and hence in [N/2,N]; then d = min(b−a, c−a) satisfies d | a², d < a, and d ≥ max(N/2−a, a²/(N−a)) ≥ a/2, contradiction.
> For ordered divisors d_i(n) put r(n) = min_i d_{i+1}(n)/d_i(n). Stef proved S(x,2) := #{n ≤ x : r(n) ≥ 2} ≥ x/(log x)^{β+o(1)}. Let H = {m odd : r(m) ≥ 2}; every m ∈ H is half-isolated (d | m², d/m ∈ [1/2,1) would give d/m = u/v with divisors u < v ≤ 2u of m). … Σ_{m ≤ X, m ∈ H} 1/m ≫ (log X)^{1−β−o(1)}. Set E_N = {mp : m ∈ H, m ≤ N^{1/2}/10, p prime, N/(4m) < p < N/(2m)}; since p > 2m each mp is half-isolated whenever m is, the representation is unique, and |E_N| ≫ (N/log N) Σ 1/m ≫ N/(log N)^{β+o(1)}.
Assessment: the deterministic part (half-isolated ⇒ conflict-free for every N) is a correct, one-line, N-uniform criterion — it is the cleanest *provable* sufficient condition for a head in (N/4,N/2) to be addable to Cambie's set. The exponent β = 1 − (1+log log 3)/log 3 ≈ 0.00415 is indeed the exponent of the *lower bound* for the exceptional set of Erdős's "close divisors" conjecture: Tenenbaum's survey "Some of Erdős' unconventional problems in number theory, thirty-four years later" (arXiv 1908.00488) states x/(log x)^{β+o(1)} ≪ R_x ≪ x e^{−c√(log_2 x)} for R_x = #{n ≤ x : no divisors d < d' ≤ 2d}, with this β (the upper bound is Maier–Tenenbaum). So the gain is genuinely sub-linear and cannot become linear: R_x = o(x). Source: Stef, PhD thesis Nancy 1992, "L'ensemble exceptionnel dans la conjecture d'Erdős concernant la proximité des diviseurs" (cited by Sawin [8] and by Tenenbaum). Numerics in §6 show the half-isolated heads are 72 % of all odd heads in (N/4,N/2) at N = 2·10^4 and 69 % at N = 4·10^5.

## 3. The positive-density lower bounds on the sibling problems (the only linear lower-bound progress anywhere)

### 3.1 W. Sawin, "Sets of unit fractions without two members whose average is a unit fraction", arXiv:2607.15419 [math.NT], 16 Jul 2026 — ARX (local `r2/sawin327.pdf/.txt`)
* **Theorem 1.** For N ≥ 1 let A_N = {a ≤ N : for every b ≤ N with b ≠ a and Ω(b) ≤ Ω(a), a+b ∤ 2ab}. Then (1) a+b ∤ 2ab for distinct a,b ∈ A_N; (2) there is c > 0 with |A_N| > cN for all large N. (Negative answer to the second question of 327; also gives sets of unit fractions with no 3-term AP, improving Korsky.)
* Explicitly: "We have made no effort to compute the constant c … It seems near certain that the best possible lower bounds … will come from a different set A defined by a more complicated condition." And for the first question (a+b ∤ ab): "Our method also gives a lower bound for that problem, but worse than the bound arising from the set of odd numbers."
* Method (§1): Lemma 2: a+b | 2ab ⇔ ∃ coprime u,v with u(u+v) | 2a and b = av/u. Lemma 3: a ∈ A_N if u(u+v) ∤ 2a for all coprime (u,v) ≠ (1,1) with v ≤ uN/a, Ω(v) ≤ Ω(u). Work inside S = {a ∈ [δN,N] : no prime factor < L, Ω(a,x) ≤ (1+ε) log log x ∀x ≥ e}; Lemma 4: |S| ≥ (1/2+o(1))(1−δ)N Π_{p<L}(1−1/p) (Tenenbaum Thm III.3.5). Lemma 5: |{a ∈ S : u(u+v) | 2a}| ≪ 4^{−Ω(u)} 4^{−Ω(u+v)} 4^{(1+ε) log log(u+v)} (N/(u(u+v))) [(log(u+v))^{−3/4}(log L)^{−1/4} + (log(3N/(u(u+v))))^{−3/4}]. Lemma 6 (the crucial one, from de la Bretèche–Tenenbaum, Math. Proc. Camb. Phil. Soc. 180 (2025), Thm 3.1, forms X_1, X_2, X_1+X_2): Σ_{u∈[X,2X], v ≤ u/δ, (u,v)=1} g_1(u)g_2(v)g_3(u+v) ≪ X²(log X)^{−7/4}(log L)^{−3/4}. Lemma 7: the sum over dyadic X converges because log 4 < 3/2 ("the key fact"), so the fraction of bad a ∈ S is < 1/2 for L large.
* Origin (author's narrative): Cambie's N = 500 optimum → ChatGPT observed that in a conflicting pair the larger element is usually absent → "the set of a with a+b ∤ 2ab for all b < a is the set of integers with no two divisors of ratio < 2 (Hooley Δ(n)=1), whose lower bound (Stef) is too weak" → replace b < a by Ω(b) ≤ Ω(a).
* Reusable for 302? The *orientation trick* (order conflicts by Ω, keep an element only if it is the Ω-maximal member of every conflict it lies in) is a generic way to turn a "delete one element per conflict" problem into a computable one-sided criterion, and the analytic engine bounds conflicts per element by O(1). It does not give explicit constants.

### 3.2 D. Della Pietra, "Erdős Problem 301: a two-sided estimate…" — CLAIM (GitHub repo + Lean; local clone `/home/user/donalddellapietra/erdos-301-proof`, paper `paper/main.tex`, PDF `erdos-301-positive-density-della-pietra.pdf`)
* **Theorem (main.tex, thm:main).** There are absolute constants ε > 0 and N_0 such that for every N ≥ N_0 there is A_N ⊆ {1..N} containing no forbidden relation 1/a = Σ_{i≤k} 1/b_i (distinct entries, any k ≥ 2) with |A_N| ≥ (1/2+ε)N.
* **Lemma (upper-third localization).** H ⊂ (N/3,N/2) ∩ (2ℕ+1), T ⊆ [⌈N/2⌉,N]: every forbidden relation in H ∪ T has length 2, head in H, both endpoints even in T, and unique coordinates a = trs, b = tr(r+s), c = ts(r+s), (r,s)=1, r < s < 2r.
* Construction: T = centered-regular subset of top half; H = centered-regular L-rough odd integers in (N/3,N/2) (source ≍ Nρ_L); conflicts O(N(log L)^{−2+θ}), θ < 1; delete conflicting heads; ε = ρ_L/24.
* README statements (verbatim): "**The proven ε is extremely small** … Neither the manuscript nor the Lean development extracts a numerical value of ε." "The committed verifier computes the construction exhaustively at N = 10^6, L = 7: of 44,445 rough odd heads in (N/3,N/2), only 4,242 are deleted, leaving … density 0.5402." "**Ceiling of the method.** Any set built this way inside (N/3,N] is capped at density 7/12 ≈ 0.583, since (N/3,N/2) contains only ≈ N/12 odd integers. Going beyond requires admitting elements below N/3, where length-three relations reappear…" "**No known method closes the gap.**"
* Upper bound (301): f(N) ≤ (15437/19344+o(1))N ≈ 0.7980 via divisor fibers of M = 5040 (certificates reproduce Wang's 667/806 for 720, 4865/5952 for 1680, 839/1040 for 2520).
* Relevance to 302: this is the construction already imported by `/home/user/erdos302`; for 302 the head range widens to (N/4,N/2) (only k = 2 exists anyway), which is what the repository's "odd quarter padding" exploits to get 5/8+δ.

### 3.3 D. Della Pietra, "A positive-density improvement over the odd numbers in Erdős Problem 327" (v1, 29 Jul 2026) — CLAIM with Lean (local `r2/dellapietra327.pdf/.txt`; PDF from https://github.com/donalddellapietra/erdos-327-proof/releases/download/proof-claim-v1/erdos-327-positive-density-della-pietra-v1.pdf)
* **Theorem 1.1.** ∃ absolute ε > 0, N_0: f_1(N) ≥ (1/2+ε)N for N ≥ N_0 (f_1 = largest 1-admissible set, a+b ∤ ab). **Theorem 1.2** (even-endpoint form): ∃η > 0 and 1-admissible A_N ⊆ {1..2N} with |A_N| ≥ (1+η)N. **Corollary 4.3** reproves Sawin: f_2(N) ≥ cN.
* Construction (§7): S_N = L-rough (Ab,Kb)-regular integers in [N/2,N]; delete b having d ≤ N, d ≠ b with b+d | 2bd and Ω(d) ≤ Ω(b) → B_N (2-admissible, |B_N| ≥ Nρ_L/8). O_N = odd a ≤ 2N that are (Ao,Ko)-regular with Ko = ⌈c log log L⌉ (N − |O_N| ≤ Nρ_L/32). Γ_N = odd a ∈ O_N with some b ∈ B_N, a+2b | ab (|Γ_N| ≤ E_N ≤ Nρ_L/32). **A_N = (O_N \ Γ_N) ∪ 2B_N**, |A_N| ≥ N + Nρ_L/16, η = ρ_L/16.
* Key lemma 5.1 (mixed coordinates): for odd a,b: a+2b | ab ⇔ a = tw(2u+w), b = tu(2u+w), (u,w)=1 — again three linear forms U, W, 2U+W. Prop. 5.2: if E := M + α + β + 2s − 4 < −1 (M = Ab log qb + Ao log qo, α = 1/qb, β = 1/qo, s = 1/(qb qo)) then E_mix ≪ qb^{Kb} qo^{Ko}{N(log L)^{−2} + o_L(N)}. Certified parameter window (Table 1): Ab = 1.000001, Ao = 1.16312, zo = 1.34305, qb = 2.48933, qo = 1.34288, c = 3.3912; mixed exponent < −1.0004.
* Structural novelty relative to Sawin: the *two-endpoint* centered budgets (different budgets on the odd host and on the rough doubled source), and the observation that the "odd-host + doubled-rough-source" mix is a positive-density improvement over the "closed class" (odd numbers). This is the closest analogue to what 302 needs: 302's closed classes are "odd numbers" and "top half"; Cambie mixes them; the next step would be to add a *doubled rough source* below N/2 (see §5 idea 1).

### 3.4 Sawin's forum comment (Problem 327, 2 Jul 2026) on the greedy set
The set G = {a : a+b ∤ 2ab ∀ b < a} contains all a = p_1⋯p_k with p_1⋯p_{i−1} ≤ p_i/2 ∀i, whose count is N/(log N)^{0.3588…+o(1)} where 2^{α−1} = 1−α. Greedy densities: 0.688 at N = 500, 0.6508 at N = 5000 (for the a+b ∤ 2ab problem). Sub-linear like the Stef approach.

### 4.2 Y. L. Liu, "Upper bounds for Erdős Problem #327 and its k-variant" (writeup, May 2026, https://leon2k2k2k.github.io/assets/pdf/erdos/erdos327.pdf; script erdos327_cert.py) — CLAIM (hand-verified, GPT-5.5 + Rethlas assisted)
**Theorem 19.** For every k ≥ 1, finite prime set P, cutoff X: α_k := limsup f_k(N)/N ≤ 1 − ρ_P·(H_P(X) − Φ_P,k(X)), where H_P(X) = Σ_{c∈S_P, c≤X} 1/c, ρ_P = Π_{p∈P}(1−1/p) = H_P(∞)^{−1}, and Φ_P,k(X) = β_s/c_s + Σ_{j<s} β_j(1/c_j − 1/c_{j+1}) with β_j = max size of a k-admissible subset of the first j P-smooth integers. **Theorem 6.** α_1 ≤ 0.7769, α_2 ≤ 0.7630 (P = {2,…,13}, X = 2000); also α_3 ≤ 0.6089. Proof: smooth–rough decomposition n = m·c, fibers A_m = {c : mc ∈ A} are k-admissible. Note: this is *exactly* the same "disjoint divisor-block / fiber" scheme as the repository's 0.8609 for 302 and Della Pietra's 0.7980 for 301, so nothing new for 302, but Liu's table shows that at this scale doubling X beats adding primes.

## 5. Ideas for the 302 lower bound extracted from these sources (ranked; my own synthesis unless attributed)

1. **Mixed "odd host + doubled rough source" à la Della Pietra-327, transplanted to 302.** Base A_0 = {odd ≤ N/4} ∪ [N/2,N] (Cambie). Add 2B where B ⊂ (N/8,N/4) consists of odd, L-rough, centered-regular integers, so 2B ⊂ (N/4,N/2) has v_2 = 1. Every conflict involving a new element is a three-linear-form event: head 2b with tails (both v_2 ≥ 2 in top half) or (one odd tail in top half + one tail of v_2 = 1); head odd a ≤ N/4 with tails 2b and c ∈ [N/2,N] (needs r+s ≡ 2 mod 4 in a = trs, 2b = tr(r+s)); head 2b with tail 2b'. All are counted by Σ over (t,r,s) with roughness on two of the three forms — precisely the situation handled by de la Bretèche–Tenenbaum in Sawin/Della Pietra. Expected outcome: another qualitative 5/8 + δ' with δ' ≍ ρ_L/const, and (unlike odd heads) this source is *not* capped by the size of odd(N/4,N/2): the whole even half of (N/4,N/2) (N/8 numbers) becomes available, and one may also try B ⊂ (N/16,N/8), 4B, etc. Why it might work: the N = 1000 optimum (§6.3) already contains 65 of the 124 even numbers in (N/4,N/2), predominantly 2·(rough) numbers. Main risk: proves only non-explicit δ, i.e. the same type of result the repository already has; the mixed conflicts "odd a ≤ N/4 + tail 2b" have a divergent (log N) unweighted count and require the centered budgets to converge.
2. **Prove an explicit constant by replacing the analytic engine with elementary explicit counting on a *finite* rough set.** Observation from the parametrisation: a prime head p ∈ (N/4,N/2) never conflicts (d | p² forces d = 1 → c = p²+p > N); a semiprime head pq (p<q) conflicts only if q < 3p. In general a head a ∈ (θN) conflicts only if a² has a divisor in the window [max(1/2−θ, θ²/(1−θ))N, θN) — a window of log-length ≤ log 2 at a prescribed position. For explicit constants one could fix a small L (e.g. L = 7 or 11) and count exactly, for a with all prime factors ≥ L and a bounded number of prime factors, the fraction with a divisor in that window: this is a finite sieve computation with explicit error terms (Brun–Titchmarsh / Selberg upper sieve with explicit constants) rather than Tenenbaum III.3.5. Why it might work: numerically at L = 7 and N = 10^6 only ~10 % of rough heads in (N/3,N/2) are conflicted (Della Pietra README); a sieve with explicit constants at fixed L is standard. Main risk: heads with many prime factors (regular but large Ω) carry the divisor mass; controlling them explicitly is where Della Pietra needs the centered budget; explicit versions of III.3.5 exist (Halberstam–Richert type) but constants are ugly. Target: something like f(N) ≥ (5/8 + 0.01)N with all constants explicit — modest but a genuine advance over "qualitative δ".
3. **Half-isolated heads as a provable N-uniform criterion (SamKorsky) + Stef/Tenenbaum.** Use the criterion "no divisor of a² in [a/2,a)" as the certificate that a head is conflict-free for *all* N; then a lower bound reduces to counting half-isolated odd integers in (N/4,N/2), a pure anatomy-of-integers question. This is the right *formalisable* object (no dependence on N in the head test) but is provably sub-linear (density of half-isolated integers → 0 by Maier–Tenenbaum). Use only to formalise/quantify the "+N/(log N)^{0.004}" gain, or in combination with 1–2 as a pre-filter. Risk: no linear gain possible.
4. **Ω-orientation (Sawin) for the 302 hypergraph.** Instead of "delete every conflicting head", keep a ∈ (N/4,N/2) odd iff a is Ω-maximal (or Ω-minimal) among the three members of every conflict triple it lies in, and similarly allow deleting *tails* that are Ω-extremal. This is the trick that turned Stef's too-weak density into positive density for 327. Numerically (§6.1) allowing tail deletions gains only ≈ 0.003 at N ≤ 3·10^6, so the payoff for 302 is small unless combined with a rough source. Risk: in 302 the conflicts are 3-uniform, and the tails are shared with heads below N/4 (Cambie's odd set), so Ω-orientation on tails also interacts with the base set.
5. **Fiber (smooth–rough) viewpoint for *constructions*, not just upper bounds.** Liu/Della Pietra/repository upper bounds decompose n = m·c (c P-smooth). Dually, a construction can be specified fiberwise: choose for each P-rough m a subset C_m ⊆ S_P ∩ [1, N/m] that is 302-free *and* compatible across fibers (a conflict a = trs, b = tr(r+s), c = ts(r+s) mixes fibers only through r+s). For P = {2,3} and a small cutoff, one can optimise the fiberwise pattern by MILP with a *proof* that cross-fiber conflicts are controlled by roughness of m. The N = 1000 optimum's avoidance of multiples of 3 among added evens (17 of 83) suggests the {2,3}-pattern matters. Risk: cross-fiber conflicts are exactly the hard three-form sums; without an analytic input this becomes again a finite computation valid only for bounded N.
6. **Korsky's random-affine-filter idea** (select odd n by n^{−1} mod q in a structured subset of F_q) transfers to any equation that is linear in the reciprocals: 1/a = 1/b + 1/c means a^{−1} = b^{−1} + c^{−1} mod q, so a "sum-free" set R ⊆ F_q of density 1/3 (e.g. the middle third) filters *even* numbers too: choose R sum-free, keep n ≤ N with q ∤ n and n^{−1} mod q ∈ λR + μ; the only surviving conflicts are those where a, b, c are not all distinct mod q in a way that is compatible… (for sum-free R, a^{−1} = b^{−1}+c^{−1} with all three in R is impossible, so *no* triple survives at all!). This gives a 302-free set of density ≈ (1/3)(1 − 1/q) among *all* integers — worse than 1/2, but it is a completely different, explicit family; mixing it with the closed classes (e.g. apply the filter only to the even numbers below N/2 and check compatibility with odd ≤ N/4 and [N/2,N]) is an unexplored explicit-constant idea. Risk: the filter is blind to the interval structure; cross-terms between filtered evens and the unfiltered classes must be counted, and the density-1/3 loss inside the filtered class is heavy (a first estimate for "top half ∪ odd ≤ N/4 ∪ (sum-free-filtered evens in (N/4,N/2))" is 5/8 + (1/8)(1/3)·(fraction compatible) ≤ 0.667 before cross-conflict deletions).
7. **Upper-bound side, for calibration:** the fiber method (Liu's Theorem 19 with k-admissibility replaced by 302-freeness) with P = {2,3,5,7,11,13}, X = 2000 should be run for 302 to see how far below 0.8609 it goes; the observed exact values ≈ 0.827 at N ≈ 10^3 and greedy 0.80 at 3·10^6 suggest the true constant is ≤ 0.80 and that the fiber bound can reach ≈ 0.80 as well, which would sharpen the target for constructions.

## 7. Open questions raised by this sweep
* Is there any way to make the de la Bretèche–Tenenbaum-based conflict bound explicit at a fixed small L (say L = 7), so that the 5/8+δ becomes 5/8 + 0.01 with a certified constant? Nobody (Sawin, Della Pietra) has tried; Sawin explicitly declines to optimise.
* Does the doubled-rough-source construction (idea 1) actually beat "all conflict-free odd heads" numerically at N ~ 10^6 (0.727), i.e. is there a *practical* gain from even numbers in (N/4,N/2), or only a theoretical one?
* What is the true growth of the conflicted-head share (≈ 0.008 per unit ln N observed): does it tend to 1 (Maier–Tenenbaum-type) — almost surely yes — and at what N does "top half ∪ all odds ≤ N/2 minus conflicts" fall below 5/8?
* What are Woett–Tang's unpublished 301 methods, and does rickyc's "fix a scale t, top layer" approach say anything about lower bounds (he mentions counterexamples)?
* Is Wang's Zenodo preprint (blocked here) purely the 720-divisor certificate, as Della Pietra's reproduction suggests? (Assumed yes.)
